# Network and integrity illustration

This source example is intentionally illustrative. The `.example.test` origin,
codec bundle, consumer-owned alternate image, codec families, and integrity tokens are
placeholders; it must not be described as a live endpoint. Replace every
source with the matching immutable asset URL plus the exact `data-codec` and
`integrity` from `build.json` before running `npm install` and `npm run build`.

Create a project JSON and compile its bundle with
`npx @pixel-point/aval-compiler compile motion.json --out motion`.
