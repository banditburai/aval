# Zero-configuration loop illustration

This source example is illustrative: the `orbit` codec bundle and `orbit.png`
are placeholders and are not included here. Supply those files (or change the
paths), then copy the compiler's `build.json.sourceMarkup` family declarations
and optional per-file integrity values before running `npm install` and
`npm run build`.

Create a project JSON and compile its bundle with
`npx @pixel-point/aval-compiler compile motion.json --out orbit`.
