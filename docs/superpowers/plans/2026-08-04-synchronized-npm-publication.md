# Synchronized npm Publication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a safe operator script that synchronizes one version across the AVAL package set, prepares verified npm tarballs, and publishes the six public packages together under `@pixel-point`.

**Architecture:** Keep `config/release/release-policy.json` as the version and package-set authority. A Node helper owns structured version synchronization, the existing deterministic packer owns artifacts, a small registry publisher owns staged npm mutations, and a POSIX shell script presents `bump`, `prepare`, and `publish` commands.

**Tech Stack:** POSIX shell, Node.js ESM, npm workspaces/registry CLI, TypeScript, Vitest.

- [x] **Step 1: Add a failing propagation regression test**

Inject a `wait` function and configure the registry adapter so a successful
publish is followed by two missing reads before the exact integrity and `next`
tag become visible. Assert publication succeeds and that polling occurred.

```ts
const adapter = registryAdapter();
const readVisibleState = adapter.read.getMockImplementation()!;
let hiddenReads = 2;
adapter.read.mockImplementation(async (name, version) => {
  if (name === RELEASE_PACKAGE_NAMES[0] &&
      adapter.publish.mock.calls.length > 0 && hiddenReads > 0) {
    hiddenReads -= 1;
    return { name, version, integrity: null, tags: {}, deprecation: null };
  }
  return readVisibleState(name, version);
});
const wait = vi.fn(async () => undefined);
await expect(publishPublicPackages({
  releaseSet: releaseSet(),
  execute: true,
  adapter,
  convergence: { attempts: 4, delayMs: 1, wait }
})).resolves.toMatchObject({ mode: "executed" });
expect(wait).toHaveBeenCalledTimes(2);
```
